# Storyboard

Paleta do blog ("Sódio"): fundo asfalto escuro, destaque em âmbar quente. Tipografia sem serifa, grande.

1. **Gancho.** Linha de README digitada letra a letra: "curadoria de notícias com IA". A palavra "curadoria" pisca em âmbar e recebe um risco.
2. **A esteira.** Relógio com quatro marcações (6h, 11h, 15h, 20h); a cada marca um card de edição sai de uma esteira. Contador sobe até 150+.
3. **Os verbos.** Os verbos (coletar, agrupar, traduzir, resumir, publicar) passam pela esteira como caixas. Duas caixas vazias no fim, rotuladas "decidir" e "responder", ficam paradas.
4. **Curadoria.** Tela dividida: à esquerda "critério" com balão de fala; à direita "dono" com uma assinatura sendo desenhada. Um selo "nota 3/5" encolhe para virar só um ponto.
5. **Imutável.** Card "Manhã, 6h" com um erro sublinhado; um cadeado fecha; as edições seguintes passam por cima sem tocar nele.
6. **O ciclo.** Loop animado: "texto ruim" → "mais regra" → "texto ruim" → "mais trava". Gira cada vez mais rápido.
7. **A posição.** O loop para. Texto em tela cheia: "A última decisão tem nome."
8. **O fluxo do blog.** Diagrama: agente → Pull Request → olho (leitura) → botão "Merge" → site. O botão Merge vira uma assinatura.
9. **O que muda.** Três itens entram com check: nome honesto, errata, revisão onde há opinião.
10. **Selo.** Aviso "Escrito e revisado por IA" no topo de um post; um segundo agente marca o PR como revisado e o merge publica. Fecha com logo e URL do blog.

Assets: ícones genéricos (sem marcas), trilha lo-fi, captura desfocada do README do fast-news só como textura.
